# tim-servo —— 编码器调舵机角度

## 实验目的

用 TIM4 的通道 3 输出标准 50 Hz 舵机控制信号（脉宽 0.5–2.5 ms 对应 0–180°），再用旋转编码器当「角度旋钮」实时改变脉宽，理解舵机的 PWM 时序要求以及「把物理量线性映射到比较寄存器」的换算方法。

> 目录名 `serov` 是 `servo` 的笔误，仓库里统一为 `tim-servo`。

## 硬件连接

| 信号 | 引脚 | 说明 |
|---|---|---|
| 舵机信号 | `PB8` (TIM4_CH3) | 接 SG90/MG996R 的信号线（橙/黄） |
| 编码器 A / B | `PA8` / `PA9` (TIM1_CH1/CH2) | 增量式编码器，3.3 V 供电 |
| 舵机电源 | — | **5 V 独立供电**，GND 与 MCU 共地 |

## 关键配置

| 项目 | 值 | 说明 |
|---|---|---|
| TIM4 `PSC` | 720 - 1 | 72 MHz / 720 = **100 kHz → 1 个计数 = 10 µs** |
| TIM4 `ARR` | 2000 - 1 | 2000 × 10 µs = **20 ms 周期，即 50 Hz** |
| TIM4 通道 | CH3，PWM1 模式 | 输出到 `PB8` |
| `COUNT_MAX` | 20 | 编码器有效行程 0–20 |
| CCR 范围 | 50 – 250 | 对应 0.5 ms – 2.5 ms |

## 角度换算

舵机标准时序：

| 脉宽 | 角度 | CCR（10 µs/计数） |
|---|---|---|
| 0.5 ms | 0° | 50 |
| 1.5 ms | 90° | 150 |
| 2.5 ms | 180° | 250 |

代码里的映射写得很紧凑：

```c
duty = (10 * count / (float)COUNT_MAX + 2.5) / 100.0 * 2000;
```

展开就是 `CCR = 10 × count + 50`：`count = 0 → 50`（0.5 ms，0°），`count = 20 → 250`（2.5 ms，180°）。**每转一格编码器，角度变化 9°**（180° / 20 格）。

## 程序流程

```c
HAL_TIM_Encoder_Start(&htim1, TIM_CHANNEL_ALL);   // 编码器当旋钮
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_3);         // 输出舵机 PWM

while (1) {
    count = __HAL_TIM_GET_COUNTER(&htim1);
    if (count > 6000)        { count = 0;       __HAL_TIM_SET_COUNTER(&htim1, 0); }
    else if (count > COUNT_MAX) { count = COUNT_MAX; __HAL_TIM_SET_COUNTER(&htim1, COUNT_MAX); }

    duty = (10 * count / (float)COUNT_MAX + 2.5) / 100.0 * 2000;
    __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_3, duty);

    HAL_Delay(10);
}
```

## 现象

旋转编码器，舵机臂在 0–180° 之间平滑跟随。顺时针转到头停在 180°，逆时针转回 0°。

## 备注

- **舵机绝不要从板子的 3.3 V 取电**。SG90 空载约 100 mA、堵转可到 700 mA 以上，接 MCU 的稳压器会直接把电压拉塌，表现为单片机反复复位或舵机抽搐。用独立 5 V 电源，并且**共地**。
- 编码器计到 20 后被钳位并写回计数器；继续转不会越界。反向转到底时计数器会从 0 下溢到 65535，被 `> 6000` 分支捕获后归零，所以不会出现异常角度。
- `HAL_Delay(10)` 决定了跟随的响应速度；舵机本身转动一圈约需 0.1–0.2 s，10 ms 的刷新足够了，再快也没有意义。
- 不同舵机的脉宽范围略有差异（有的 0.4–2.6 ms），MG996R 这类金属齿舵机行程可能超过 180°，若发现到达极限还在顶，说明脉宽超范围，需要把映射范围收窄，否则会烧舵机齿轮或堵转发热。
- 想做「平滑转动」可以把 `__HAL_TIM_SET_COMPARE` 的目标值做插值渐变，而不是直接跳变——直接跳变会让舵机以最大速度冲过去，冲击电流很大。
